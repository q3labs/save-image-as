# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Include what you found, the browser and version, and steps to reproduce it.

We aim to acknowledge a report within a few days and will keep you updated until it is fixed.

## Scope

The extension runs entirely in your browser and collects no data. The most useful reports concern: reading or sending data the extension should not touch, unsafe handling of images or SVG files, and excessive permissions.
